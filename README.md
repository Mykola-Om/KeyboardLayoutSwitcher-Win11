# KeyboardLayoutSwitcher-Win11 (Перемикач розкладки)

Утиліта для Windows 11, яка автоматично виправляє слова, набрані не в тій розкладці — між українською та англійською.

## 🌟 Основні можливості

- **Автозаміна розкладки:** розпізнає «абракадабру» (`ghbdsn` → `привіт`) і переписує слово правильно, перемикаючи розкладку.
- **Скасування одним натисканням:** якщо виправлення було зайвим, `Backspace` одразу після нього повертає рядок точно як було, разом із попередньою розкладкою.
- **Відновлення апострофа:** `память` → `пам'ять`, `компютер` → `комп'ютер`. Працює за словником, тож слова, які пишуться без апострофа (`свято`, `цвях`, `морквяний`), лишаються недоторканими.
- **Розкладка для програм:** можна прив'язати мову до програми — коли її вікно стає активним, вмикається задана розкладка. Ручний вибір має пріоритет: якщо перемкнути мову у вікні самому, воно більше не чіпається, доки не закриється.
- **Фільтр програм:** режими «працювати тільки у вибраних» або «працювати всюди, крім вибраних».
- **Слова-винятки:** список слів, які алгоритм ніколи не перекладає.
- **Виправлення при Enter:** у браузерах Enter підтверджує підказку адресного рядка, тому там виправлення на Enter вимкнене — інакше замість переходу на сайт починався б пошук. Решта меж (пробіл, кома, крапка) працює як звичайно.
- **Робота у фоні:** живе в системному треї, вміє запускатися разом із Windows, захищена від подвійного запуску.

## 🚀 Як користуватись

1. Запустіть програму. Вікно можна закрити чи згорнути — робота продовжиться у треї.
2. Увімкніть **«Автоматична заміна розкладки»**.
3. За потреби налаштуйте:
   - **програми**, де автозаміна має ігноруватися (ігри, термінал);
   - **розкладку для програм** — кнопка «Активна» дає 3 секунди, щоб перемкнутись на потрібне вікно, і підставляє його назву;
   - **слова-винятки**, які не слід чіпати.
4. Пишіть як звикли. Забули перемкнути мову — утиліта помітить і виправить.

Налаштування зберігаються в `%LOCALAPPDATA%\KeyboardLayoutSwitcher\settings.xml` і застосовуються на льоту.

## 🧠 Як приймається рішення

Виправляти слово чи ні — вирішує кілька перевірок поспіль:

1. **Словники.** Якщо слово є в словнику поточної мови, його не чіпають. Це найнадійніший сигнал, тому словники великі:

   | Файл | Записів | Призначення |
   |---|---|---|
   | `Dictionaries/uk.txt` | 9786 | українські слова |
   | `Dictionaries/en.txt` | 9896 | англійські слова |
   | `Dictionaries/tech.txt` | 101 | технічні терміни, які пишуть латиницею |
   | `Dictionaries/uk-apostrophe.txt` | 291 | слова з апострофом (ключ без апострофа виводиться автоматично) |

2. **Контекст.** Слова поряд із `.`, `_`, `/`, `\` та переходом регістру (camelCase) не чіпаються — це імена файлів, змінних і шляхи: `.env`, `MY_VAR`, `src/components`.

3. **Евристика.** Якщо слова немає в словнику, порівнюються два варіанти написання за «неприродністю»: довгі ланцюжки приголосних, відсутність голосних, неможливі для мови пари приголосних. Набір таких пар будується з самих словників, окремо для кожної мови, тому текст, набраний не в тій розкладці (`lhjy`, `ghjusy`), отримує штраф, а справжні слова — ні.

Розкладка клавіш не зашита в код: символи запитуються в самої розкладки через `ToUnicodeEx`. Це важливо, бо користувацька українська розкладка може відрізнятися від стандартної — наприклад, на клавіші `~` одна дає апостроф, а інша `ё`.

## ⚙️ Технічні деталі

C# / WinForms, .NET Framework 4.7.2. Глобальні хуки клавіатури й миші (`SetWindowsHookEx`), відстеження активного вікна (`SetWinEventHook`), нативна темна тема (`DwmSetWindowAttribute`, `SetWindowTheme`).

Словники завантажуються один раз при старті; результати рішень кешуються з урахуванням контексту межі слова.

### Збірка та тести

```
dotnet build KeyboardLayoutSwitcher.csproj
dotnet build Tests\KeyboardLayoutSwitcher.Tests.csproj
```

Тести — власний раннер (без xunit), запускається як звичайний exe:

```
Tests\bin\Debug\KeyboardLayoutSwitcher.Tests.exe
```

Покривають евристику `KeyMapper`, відновлення апострофа, кеш, розбір налаштувань, рішення про розкладку для програм і опитування розкладок.

> Якщо програма запущена, вона тримає `bin\Debug\KeyboardLayoutSwitcher.exe` — перед збіркою її треба закрити, або зібрати з іншим виходом: `-p:OutputPath=<шлях>`.
